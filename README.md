# HR Absenteeism Dashboard

## Project Overview
This project analyzes employee absenteeism data using Power BI.

## Tools Used
- Power BI
- SQL
- GitHub

## Key Performance Indicators
- Total Records: 740
- Total Absenteeism Hours: 5K
- Average Absenteeism Hours: 6.92
- Maximum Absenteeism Hours: 120

## Dashboard Analysis
The dashboard analyzes absenteeism patterns by:
- Month
- Day
- Season
- Reason for absence

All charts use average absenteeism hours for comparison.

## Project File
The Power BI dashboard is included in this repository as a `.pbix` file.
