# SQL Analysis – HR Absenteeism

This folder contains SQL queries used to analyze employee absenteeism data.

## Database

- Database: Oracle
- Table: ABSENTEEISM
- Records: 740
- Columns: 21

## Analysis Performed

1. Overall absenteeism KPI analysis
2. Absenteeism by reason
3. Absenteeism by month
4. Absenteeism by day of week
5. Absenteeism by season
6. Transportation expense analysis
7. Hit target analysis
8. Disciplinary failure analysis
9. Social drinker analysis
10. Social smoker analysis
11. Age group analysis
12. Distance from residence to work analysis

| Metric | Result |

## Tools Used

- Oracle SQL

## Purpose

The analysis helps identify patterns in employee absenteeism and provides
data-driven insights that can support HR workforce planning and monitoring.
